Lecture Hub

Учебная платформа с каталогом преподавателей и курсов.

Стек и версии

JavaScript, JSX, CSS, React 18.3.1, React DOM 18.3.1, Vite 8.3.1.
Для запуска подойдёт Node.js 22.12.0 или новее.

Установка и запуск

В папке проекта выполните:

    npm ci
    npm run dev

Откройте адрес из терминала, обычно http://localhost:5173.

Сборка:

    npm run build

Просмотр сборки:

    npm run preview

Структура папок

    public/lecturers/   фотографии преподавателей
    src/components/    общие компоненты, TextField и модальные окна
    src/pages/         главная, каталог лекторов и каталог курсов
    src/data/          данные преподавателей и курсов
    src/App.jsx        основной компонент и навигация
    src/main.jsx       точка входа
    src/styles.css     стили
    dist/              результат сборки

Данные и роутинг

Данные находятся в src/data/lecturers.js. Массив lecturers содержит
преподавателей, их курсы и цены. Массив allCourses формируется из lecturers.

Навигация реализована в src/App.jsx через состояние page и функцию navigate.
Значения home, lecturers и courses переключают страницы без изменения URL.
Пункты about и partners прокручивают главную к соответствующим разделам.

Управление фокусом поля ввода

Компонент src/components/TextField.jsx построен на forwardRef и useImperativeHandle.
Родитель может управлять фокусом:

    const searchRef = useRef(null);

    <TextField ref={searchRef} ... />

    searchRef.current?.focus();

Кнопка «Фокус на поле» на странице «Лекторы» демонстрирует работу.
При сбросе фильтров фокус возвращается в поле поиска.
Компонент также используется в поиске курсов и форме записи.

Проверка:

1. Откройте страницу «Лекторы».
2. Нажмите «Фокус на поле» — курсор должен оказаться в поиске.
3. Введите запрос и нажмите «Сбросить фильтры» — фокус вернётся в поиск.
4. Откройте форму записи и проверьте поля «Ваше имя» и «Телефон или e-mail».
